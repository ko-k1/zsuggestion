# Support

Use the channel that matches your request:

- Bug reports: <https://github.com/ko-k1/zsuggestion/issues>
- Usage questions: <https://github.com/ko-k1/zsuggestion/issues>
- Security concerns: follow [SECURITY.md](SECURITY.md); do not report them
  publicly.

Before asking, check the [README](README.md), the
[documentation index](docs/INDEX.md), and existing issues. Include the project
version, operating system, shell and terminal, reproduction steps, and relevant
sanitized output.
